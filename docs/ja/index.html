ZinggumDol

一歩踏み外しても、川に落ちたわけじゃない。
思うようにいかなかった日のための、小石と話すやさしい日記。

App Storeでダウンロード

できること

小石と話す

小石のほうから声をかけます。前に話したことを覚えていて、そのあとどうなったかを聞いてくれます。選んで答えても、自分で書いてもかまいません。

声で伝える

書くのがつらい日は、話すだけで大丈夫です。音声認識はデバイス上で行われ、対応するデバイスでは話した内容が読みやすく整理されます。

歩いた道

一週間が一列の飛び石になります。踏めなかった日もそのまま残り、何も消えません。

残したもの

あったこと、そのときの気分、次に試したいことを、日付順に見返せます。

ウィジェットと通知

ホーム画面で小石のひとことを見られます。好きな時間にやさしい通知が届き、今日はどうだったかを一緒に振り返れます。

あなただけのもの

登録は不要です。記録はあなたのデバイスと、あなた自身のiCloudにだけ保存されます。アプリはパスコードでロックできます。

画面

ZinggumDol Pro

一度だけの購入で、サブスクではありません。目標を3つより多く持て、6種類の小石の質感から選べて、記録をテキストファイルに書き出せます。

新しいデバイスや再インストールのあとは、「設定」▸「購入の復元」をタップしてください。
